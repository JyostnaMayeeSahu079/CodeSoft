# 😀 Face Detection and Recognition using AI

## 📌 Overview

A full-stack Face Detection Web Application developed using Python, Flask, OpenCV, HTML, and CSS. The application allows users to upload images and automatically detects human faces using OpenCV's Haar Cascade Classifier.

## ✨ Features

- Face Detection using OpenCV
- Image Upload Functionality
- Face Counting
- Interactive Web Interface
- Fast and Lightweight Processing

## 🛠 Technologies Used

- Python
- Flask
- OpenCV
- HTML
- CSS

## 📂 Project Structure

```text
Task-3-Face-Detection/
│
├── app.py
├── uploads/
├── static/
│   └── style.css
└── templates/
    └── index.html
```

## ▶️ How to Run

Install dependencies:

```bash
pip install flask opencv-python
```

Run:

```bash
python app.py
```

Open:
```text
http://127.0.0.1:5000
```
